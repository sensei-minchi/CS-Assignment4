Mechanics of a POST-based CSRF Attack
Table 2(c) Root Cause
1. Victim Session Active

The legitimate user logs in to the corporate portal. The browser stores authenticated session cookies.

2. Attacker Site Lures Victim

Victim visits an external malicious phishing page hosting a hidden form that auto-submits a forged POST request.

3. Ambient Cookies Sent

Browser automatically attaches cookies with the cross-origin request. Insecure servers process it blindly!

Vulnerable Endpoint (/vulnerable)
